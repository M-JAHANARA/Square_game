## 🎮 About The Project

**Square Game** is a cross-platform game project developed in three different environments: Web, Python, and Android.

The project explores how the same game concept can be implemented using different technologies, with each version having its own dedicated codebase.

The repository brings all three implementations together in one place.

## 🚀 Getting Started

First, clone the repository:

```bash
git clone https://github.com/M-JAHANARA/Square_game.git
```

Navigate to the repository:

```bash
cd Square_game
```

Choose your preferred implementation:

| Version | Directory |
|---|---|
| Web | `Web/` |
| Python | `Python/` |
| Android | `Android/` |

Each implementation has its own requirements and execution process. Refer to its project files for platform-specific instructions.
