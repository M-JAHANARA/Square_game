## 🎮 About The Game

**Square Game** is a cross-platform game project developed across three different platforms: **Web, Python, and Android**.

The project explores different approaches to game development by implementing the same game concept using three distinct technology stacks.

From browser-based gameplay to a Python-powered desktop experience and a native Android application, each implementation has its own dedicated environment.

**Three platforms. Three technologies. One Square Game.**

## 💻 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/M-JAHANARA/Square_game.git
```

### 2. Enter the project directory

```bash
cd Square_game
```

### 3. Choose your preferred platform

**🌐 Web Version**

Navigate to the Web directory and open the project's HTML entry point in a browser.

```text
Web/
```

**🐍 Python Version**

Navigate to the Python directory. Make sure Python and Pygame are installed, then run the main Python file.

```bash
pip install pygame
```

```text
Python/
```

**📱 Android Version**

Open the Android project in Android Studio, configure the required Android SDK, and build or run the application on an Android device or emulator.

```text
Android/
```

<sub>Note: The exact entry-point filenames and additional requirements depend on each implementation.</sub>
